# 1. IEEE-Style Research Paper

The Phase 1 paper: five pages including references, `IEEEtran` conference
format, anonymous for review.

| File | What it is |
|---|---|
| `IEEE_Research_Paper_CabinGuard.tex` | the paper source |
| `IEEE_Research_Paper_CabinGuard.pdf` | the built paper |
| `paper_numbers.tex`, `paper_numbers_external.tex` | every number the paper quotes, as LaTeX macros, generated from the committed results |
| `figures/dashboard_detection.png` | Fig. 2, the prototype's detection panel (synthetic signals) |

Fig. 1 (signal flow) is drawn in TikZ inside the `.tex`.

## Build

```
cd 1_IEEE_Research_Paper
pdflatex IEEE_Research_Paper_CabinGuard.tex
pdflatex IEEE_Research_Paper_CabinGuard.tex          # second pass for references
python ../tools/check_manuscript.py IEEE_Research_Paper_CabinGuard.tex
```

The checker enforces the house rules in `CLAUDE.md` and the 5-page limit
(it reads the `.log` of the last build).

## Where the numbers come from

No number is typed into the paper. They are macros written by
`6_Proof_of_Concept_Prototype/prototype/experiments/export_paper_numbers.py`
from the result files in `6_Proof_of_Concept_Prototype/prototype/results/`,
which the scripts listed in [`5_Validation_Benchmarking`](../5_Validation_Benchmarking)
produce. After re-running an experiment:

```
cd 6_Proof_of_Concept_Prototype/prototype
python experiments/export_paper_numbers.py           # rewrites ../../1_IEEE_Research_Paper/paper_numbers*.tex
```

Fig. 2 is regenerated by `experiments/dashboard_figure.py` (needs Playwright).
